自回归模型和 VAE 都是**显式概率模型**——能算出 $p(x)$ 的具体值。这节课的 GAN 和扩散模型都走另一条路：**隐式概率模型**，不直接建模 $p(x)$，算不出概率密度，但能从分布中采样。

---

## GAN 生成对抗网络

### 思路：不建模概率，直接学采样

自回归模型直接最大化训练数据的似然：$p_\theta(x) = \prod_{i=1}^{N} p_\theta(x_i | x_1, \ldots, x_{i-1})$。

VAE 最大化 $p(x)$ 的变分下界，需要近似推断。

GAN 说：**直接放弃 $p(x)$。** 手里有一批真实数据样本 $x \sim p_{data}$，还有个已知的简单分布 $p(z)$（比如高斯）。让一个神经网络 $G(z)$ 把 $z$ 映射成"假数据"。改变 $G$ 的参数，假数据的分布 $p_G$ 就会变化。目标是让 $p_G = p_{data}$。

直觉：生成器 $G$ 本质上就是学一个从已知分布到数据分布的变换函数。

### 判别器：一个可学习的损失函数

光有生成器不够——怎么度量 $p_G$ 和 $p_{data}$ 的差距？

再训练一个**判别器 $D$**。$D(x)$ 输出的是 $x$ 来自真实数据的概率。真数据 → $D(x) \to 1$，假数据 → $D(G(z)) \to 0$。

两个网络对抗训练：生成器想骗过判别器，判别器想识破假货。判别器本质上是生成器的**可微损失函数**——梯度从 $D$ 传到假样本，再传到 $G$。

![GAN 训练目标](/images/lec14_gan_minimax.png)

### 极小极大博弈

GAN 的训练目标是一个极小极大博弈：

$$\min_G \max_D \; V(G, D) = \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z)))]$$

拆开看：

* $\mathbb{E}_{x \sim p_{data}}[\log D(x)]$：对真数据，$D$ 想输出 1，即最大化 $\log D(x)$
* $\mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z)))]$：对假数据 $G(z)$，$D$ 想输出 0，即最大化 $\log(1-D(G(z)))$——等价于最小化 $D(G(z))$

对 $G$ 来说，第一项不依赖它，它只管第二项：**想要 $D(G(z))$ 接近 1**——判假为真。所以 $G$ 想最小化 $\log(1-D(G(z)))$。

训练时交替更新，展开写就是：

* $D$：$D \leftarrow D + \alpha_D \frac{\partial V}{\partial D}$（梯度上升，最大化 $V$）
* $G$：$G \leftarrow G - \alpha_G \frac{\partial V}{\partial G}$（梯度下降，最小化 $V$）

### GAN 的训练难点

**$V$ 不是损失函数。** $V$ 同时取决于 $D$ 和 $G$ 的质量，不同参数组合可能得到完全一样的 $V$ 值。所以 GAN 没有可靠的损失曲线来判断收敛——没法像普通训练那样看着 loss 下降判断"训好了"。

**梯度消失问题。** 训练初期，生成器输出的是随机噪声，和真实图像差距巨大。判别器轻松完成任务，此时 $\log(1-D(G(z)))$ 的梯度接近于零——生成器收不到有效反馈。

解决方法：**非饱和损失**。把 $G$ 的目标从最小化 $\log(1-D(G(z)))$ 改为最大化 $\log D(G(z))$——等价于最小化 $-\log D(G(z))$。当 $D(G(z))$ 接近 0 时，这个损失的梯度更大，能推动 $G$ 改进：

$$\text{原版 } G\text{ 损失}: \min_G \mathbb{E}[\log(1-D(G(z)))] \quad \xrightarrow{\text{非饱和版}} \quad \min_G \mathbb{E}[-\log D(G(z))]$$

**语义理解问题。** GAN 能学到训练数据集的统计特征。比如训练集里有马、有角、有圣诞老人帽子，那要求 GAN 生成"戴圣诞老人帽子的独角兽"时，它可能真能拼出一张像样的图——尽管训练集里根本没有这张图。但判别器没这么聪明，倾向于判这张图是假的。这让 GAN 偶尔能组合出"不存在但合理"的图，也会生成语义矛盾的内容。

**容量假设。** 理论分析假设 $G$ 和 $D$ 有无限容量。实际上网络大小有限、数据量有限，梯度下降也不一定能找到最优解。

### DC-GAN 和 StyleGAN

$G$ 和 $D$ 通常是 CNN。**DC-GAN**（2015）用卷积 + 转置卷积 + 批归一化搭建了最早的稳定结构。**StyleGAN** 用更复杂的架构，把潜变量 $z$ 注入网络的不同层级，可以实现精细的风格控制。

### 潜空间插值

GAN 有一个好看的特性：潜空间是光滑的。给定两个潜向量 $z_0$ 和 $z_1$，做线性插值 $z_t = t z_0 + (1-t) z_1$，对每个 $z_t$ 生成一张图——你会看到图片从一个样子平滑过渡到另一个样子。

这证明了生成器没有"死记硬背"训练数据，而是真的学到了一个连续流形。

![GAN 潜空间插值](/images/lec14_gan_interpolation.png)

### GAN 小结

| 优点 | 缺点 |
|------|------|
| 思路简单直接 | 没有可靠的训练指标 |
| 生成质量高 | 训练不稳定 |
| 潜空间光滑可插值 | 难以扩展到大规模模型和数据 |
| — | 模式坍塌、记忆训练数据 |

GAN 在 2016–2021 年间是生成模型的主力，之后被扩散模型取代。

## 扩散模型

### 直觉：加噪→去噪

扩散模型的思路和 GAN 完全不同。

从噪声分布 $z \sim p_{noise}$（通常是单位高斯）开始，目标是把噪声"变"成数据分布 $p_{data}$ 的样本。噪声和数据的形状相同（比如都是 $H \times W \times 3$ 的张量）。

引入一个噪声等级 $t \in [0, 1]$：

* $t = 0$：纯数据，完全干净
* $t = 1$：纯噪声
* 中间的 $t$：平滑插值

神经网络的任务是：**给定一个带噪声的图像和一个 $t$ 值，学会预测要去除的噪声。** 迭代做这件事——从纯噪声开始，逐步去除一点点噪声，再去除一点点……重复几十步后就是一个干净的生成样本。

训练时网络面对的输入始终是"被中间等级噪声破坏的数据"，目标是清理这些噪声。采样时从全噪声出发，每一步调用网络去除少量噪声，逐步靠近数据分布。

### 整流流（Rectified Flow）：最干净的数学公式

2025 年的 CS231n 直接用整流流来讲扩散模型——代码只有几行，数学也最简洁。

**训练过程：** 每次迭代，从数据中抽一个 $x$，从噪声中抽一个 $z$，再随机取一个 $t \in [0, 1]$：

$$x_t = (1-t) \cdot x + t \cdot z$$

$$v = z - x$$

$x_t$ 是在 $x$ 和 $z$ 之间的线性插值点。$v$ 是从 $x$ 指向 $z$ 的向量——相当于**速度场**，告诉你从数据指向噪声的方向。网络 $f_\theta(x_t, t)$ 的目标就是预测这个向量 $v$：

```python
for x in dataset:
    z = torch.randn_like(x)          # 采样噪声
    t = random.uniform(0, 1)         # 采样噪声等级
    xt = (1 - t) * x + t * z         # 插值得到带噪样本
    v_gt = z - x                     # 真实速度向量
    v_pred = model(xt, t)            # 模型预测
    loss = (v_gt - v_pred).square().sum()  # 均方误差
```

直觉：$x_t$ 是 $x$ 向 $z$ 走了 $t$ 步的位置，模型要知道"从哪来、往哪去"。预测的速度向量指向噪声方向，训练好了，反过来走就能从噪声回到数据。

和 GAN 比，扩散模型用一个简单 L2 损失就能可靠地跟踪训练质量——loss 下降 = 模型变好。

![整流流训练流程](/images/lec14_rectified_flow.png)

### 采样（推理）

训练好之后怎么生成？从纯噪声开始，一步一步往回走。取步数 $T$（通常 50）：

```python
sample = torch.randn(x_shape)            # 从纯噪声开始
num_steps = 50
for t in torch.linspace(1, 0, num_steps):  # t: 1 → 0
    v = model(sample, t)                   # 预测当前速度向量
    sample = sample - v / num_steps        # 往数据方向走一步
```

每一步减去预测速度向量的 $1/T$——等价于欧拉法解 ODE。步数越多质量越好，但计算量越大。

### 条件整流流

要加条件 $y$（类别标签、文本嵌入等），把 $y$ 直接送进网络就行：

```python
for (x, y) in dataset:
    z = torch.randn_like(x)
    t = random.uniform(0, 1)
    xt = (1 - t) * x + t * z
    v = model(xt, y, t)                 # y 作为额外输入
    loss = (z - x - v).square().sum()
```

采样时给定条件 $y$：

```python
y = user_input()                        # 条件：文本 / 类别等
sample = torch.randn(x_shape)
for t in torch.linspace(1, 0, num_steps):
    v = model(sample, y, t)
    sample = sample - v / num_steps
```

### 无分类器引导（CFG）

条件生成有个实际问题：模型有时候不够"听话"，生成的结果和条件关联不够强。

CFG 是目前所有现代扩散模型都在用的关键技巧。训练时**随机丢弃条件**（比如 50% 概率把 $y$ 替换成空条件 $\emptyset$）：

```python
for (x, y) in dataset:
    z = torch.randn_like(x)
    t = random.uniform(0, 1)
    xt = (1 - t) * x + t * z
    if random.random() < 0.5:
        y = y_null                      # 一半概率丢弃条件
    v = model(xt, y, t)
    loss = (z - x - v).square().sum()
```

这样一个模型就同时具备了两种能力：

* $v_\emptyset = f_\theta(x_t, \emptyset, t)$ 指向 $p(x)$——无条件生成
* $v_y = f_\theta(x_t, y, t)$ 指向 $p(x|y)$——条件生成

采样时，对两个方向做**外推**：

$$v_{CFG} = v_\emptyset + w \cdot (v_y - v_\emptyset)$$

$w$ 是引导强度。$w = 1$ 就是普通条件生成，$w > 1$ 放大条件的影响力。$(v_y - v_\emptyset)$ 这个差指向"条件相关"的方向，$w$ 越大，条件越强。

代价：每步采样需要两次网络前向传播（条件 + 无条件），计算量翻倍。也可以通过蒸馏把 CFG 的效果内化到单次前向中。

![无分类器引导 CFG](/images/lec14_cfg.png)

### 最优预测与噪声调度

在全噪声（$t=1$）条件下，模型的最优预测指向数据分布的均值。在无噪声（$t=0$）条件下也差不多。真正困难的是中间 $t$ 值——两个完全不同的 $(x, z)$ 对可能经过同一个 $x_t$ 点（想象两条轨迹在中间交叉），模型只能对噪声做平均加权，结果模糊。

因此实际训练时不均匀采样 $t$，而是用 **logit-normal 分布**把更多训练资源分配给中间难学的噪声等级。高分辨率数据还需要进一步偏置到更高噪声区域，因为低噪声时像素间高度相关，学习信号不强。

## 潜在扩散模型（LDM）

在像素空间直接做扩散太贵了——$256 \times 256 \times 3$ 的图每一步都要过一遍网络。真实场景（Stable Diffusion、FLUX）都在**潜在空间**里做扩散。

![潜在扩散模型架构](/images/lec14_ldm.png)

### 架构

整个管线分成三步：

1. **编码器**：把图像 $H \times W \times 3$ 映射到潜在空间 $H/D \times W/D \times C$
2. **扩散模型**：在潜在空间上训练整流流（加噪→去噪）——**编码器冻结**
3. **解码器**：把去噪后的潜在向量映射回图像

最常见的配置：$D=8$（8 倍空间下采样），$C$ 为 16 左右。编码器/解码器是带注意力机制的 CNN。

算一笔账：$256^2 \times 3 = 196\text{K}$ 个值 变成 $32^2 \times 4 = 4\text{K}$ 个值——扩散模型的输入少了近 50 倍。

### 编码器/解码器怎么训

用 VAE 框架训练——但 VAE 有模糊输出的问题，重建质量不高。解决方法：**在解码器端加一个 GAN 判别器**。VAE 的 KL 正则项保证潜在空间结构合理，GAN 判别器让解码器输出更锐利。

所以 LDM 实际上是 **VAE + GAN + 扩散模型** 的三合一架构。

## DiT：扩散 Transformer

扩散模型的骨干网络以前是 U-Net（CNN 结构），现在逐渐被 Transformer 取代——和整个深度学习的大趋势一致。

**DiT（Diffusion Transformer）** 用标准 Transformer 块做扩散，条件注入方式：

* **时间步 $t$**：通过 adaLN（自适应层归一化）的 scale/shift 参数注入
* **文本条件**：通过交叉注意力注入
* **其他条件**（如标签）：和 $t$ 一样走 adaLN

![DiT 扩散 Transformer](/images/lec14_dit.png)

### 文生图管线

工业级实现（如 FLUX.1）：

1. **文本编码器**（T5 + CLIP）把 prompt 转为 embedding，冻结
2. 随机采样潜在噪声，和文本 embedding、时间步一起送入 **DiT**（FLUX 有 12B 参数）
3. DiT 输出去噪后的潜在空间
4. **解码器**把潜在向量还原为图像

![文生图管线](/images/lec14_text2image.png)

### 文生视频

思路和文生图一致，只是潜在噪声和潜在空间多了一个**时间维度**：

* 噪声 $\mathbf{z} \in \mathbb{R}^{F \times C \times H/D \times W/D}$，其中 $F$ 是帧数
* 卷积在时空维度同时做，注意力跨越帧之间
* 其余不变：编码器 → 潜在空间加噪/去噪 → 解码器

## 扩散蒸馏

扩散模型最大的缺点是采样慢——每张图要跑 30-50 次网络前向。蒸馏技术把这个数字压到个位数：

* **渐进蒸馏**：教师模型（多步）→ 学生模型（少步），多轮递减
* **一致性模型**：训练一个网络直接从任意噪声映射到干净数据
* **对抗扩散蒸馏**：加个判别器，1-4 步采样也能保证质量

理想情况：1 步采样，还把 CFG 的效果也蒸馏进去（省去双重前向传播）。

## 其他视角

除了整流流，扩散模型还有几种等价的数学描述：

* **潜变量模型视角**：加噪过程是前向过程 $q(x_t|x_{t-1})$，去噪是反向过程 $p_\theta(x_{t-1}|x_t)$——DDPM 的原始推导
* **分数匹配视角**：网络学习 $\nabla_x \log p(x)$（分数函数），指向高概率区域
* **SDE 视角**：加噪/去噪是随机微分方程的正向/反向过程，网络学的是 SDE 的漂移项

不同视角殊途同归——整流流的优势在于训练目标简单（均方误差）、采样策略直观（欧拉积分），所以 CS231n 2025 用这个来讲。

### 广义扩散统一模板

所有扩散变体其实都共享同一个模板，区别在于系数函数：

| 变体 | $x_t$ 构造 | 预测目标 |
|------|-----------|---------|
| 整流流 | $(1-t)x + tz$ | $v = z - x$（速度） |
| VP（方差保持） | $\sqrt{\bar{\alpha}_t}x + \sqrt{1-\bar{\alpha}_t}z$ | $\epsilon$（噪声） |
| VE（方差爆炸） | $x + \sigma_t z$ | $\epsilon$（噪声） |

不同参数化在训练稳定性和采样质量上略有差异，但核心思想完全一样。

### 自回归模型回归

一个有意思的趋势：自回归模型最近在**离散潜在空间**上杀回来了。先把图像编码成离散 token（整数），然后在 token 序列上做自回归建模——本质是把图像生成变成了语言建模问题。这是 DALL-E、VQGAN 等模型的核心思路。

---

## 总结

这节课覆盖了现代生成模型的两大流派：

* **GAN**：把生成建模成生成器 vs 判别器的博弈——概念优雅，训练折腾
* **扩散模型**：把生成建模成迭代去噪——训练稳定，采样偏慢，但在工程上压倒性胜出

以及它们在实际系统中的融合：

* LDM = VAE（编码器） + GAN（锐化解码器） + 扩散（潜在空间生成）
* DiT = 扩散 + Transformer 骨干
* CFG = 条件生成的关键技巧
* 蒸馏 = 解决采样慢的工程方案

现代图像/视频生成系统（Stable Diffusion、FLUX、DALL-E、Midjourney）几乎都建立在"潜在空间 + 扩散 + CFG"这套组合拳上。
